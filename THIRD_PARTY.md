## Services used at run time

Nothing below is bundled. Each one receives the visitor's IP address and the request itself (for example the
map area being viewed, or an airline code). "Switch" says how a site owner or visitor can turn it off.
"Terms checked" records what was actually read; **where the terms were not found or are unclear this is said
plainly, and the service should be treated as unconfirmed.**

| Service | Used for | Switch | Terms checked | Verdict |
|---|---|---|---|---|
| [OpenFreeMap](https://openfreemap.org) (tiles.openfreemap.org) | default vector map and airport detail | airport detail: Settings or `airportDetail`; base map: layer picker | Free public instance, no key, attribution required (OpenFreeMap, OpenMapTiles, OpenStreetMap contributors). Donation funded, no SLA. | OK. Attribution is shown on the map. |
| [VersaTiles](https://versatiles.org) (tiles.versatiles.org) | alternative vector base map | layer picker | Free to use with attribution (OpenStreetMap contributors). Public server is best effort. | OK. |
| CARTO basemaps (basemaps.cartocdn.com) | Dark Matter style | layer picker | CARTO's free basemap use is documented as non-commercial, needs attribution (© CARTO, © OpenStreetMap contributors) and states usage limits (about 5 million requests a month on the free tier); a key may be required for some styles. | **Doubtful for a public site.** Fine for personal use. If you run a busy or commercial site, get a CARTO plan or use OpenFreeMap or VersaTiles. |
| OpenStreetMap standard tiles (tile.openstreetmap.org, tile.openstreetmap.de) | optional raster layers | layer picker (not default) | The OSM Foundation tile usage policy allows light use with attribution and a valid referrer, forbids heavy use and bulk download, and offers no service guarantee. | Optional layer, and also the last-resort fallback when every vector provider fails to load (`maplibre.js`). Do not rely on it on a busy public site. |
| `pics.avs.io` | airline logos | Settings "Airline logos" or `airlineLogos = false` | **No terms page or licence for hotlinking could be found.** The logos belong to the airlines. | **Unconfirmed. Recommend** leaving it on only for personal or low-traffic sites, or setting `airlineLogos = false` (a monogram is shown instead) or pointing `airlineLogoUrl` at a source you have rights to. |
| [planespotters.net](https://www.planespotters.net/photo/api) public API | aircraft photos | Settings "Photos from planespotters.net" or `planespottersAPI = false` | Existing upstream tar1090 feature. The API page asks for credit and a link back to the photo, which the info panel shows; **no explicit statement about hotlinking volume was found.** Photos stay the property of their photographers. | Credit is shown. Unconfirmed beyond that. |
| adsb.im route API (`routeApiUrl`) | flight routes | Settings "Look up routes" or `useRouteAPI`; **off by default** | **No terms were found.** The aircraft callsign and position are sent. | Off by default. Do not enable on a public site without asking the operator. |
| graphs1090 (on your own server) | classic graphs link | none needed, local | GPL v2+ (wiedehopf/graphs1090). Runs on your host, no third party. | OK. |
| OurAirports (data) | airport, runway and frequency data in `html/airport-db/airports.json`, built by `tools/build-airports.py` | none, vendored | Public domain (see ourairports.com/data). Refresh with the script. No ILS data exists in it. | OK. |
| aviationweather.gov Data API | METAR and TAF, fetched server-side by the recorder (never by browsers) | `SW_WX=0` or Settings "Airport weather" | Read on the API's page: 100 requests a minute, most endpoints cap at 400 results, set a custom User-Agent, no CORS. We make 2 requests every 5 minutes with a descriptive User-Agent and back off on HTTP 429. **The OpenAPI spec returned 403 and was not read**: the parameters used (`bbox`, `format=json`) were checked by sending requests and reading the responses. No licence or redistribution statement was found on the pages read (it is US government data). | Reasonable, but republishing the reports in `wx.json` on a public site is your call. |
| SkyVector, NATS UK AIP, Wikipedia | links opened by the visitor from the airport panel, never embedded | `airportLinks = false` | URLs fetched on 2026-11-08 for EGLL, EGGW, EGCC, KJFK, LFPG: SkyVector and Wikipedia resolved (HTTP 200); the NATS AIP landing page resolved but a per-airport AIP page needs the current AIRAC date, so only the landing page is linked. The OurAirports website was not linked: its TLS certificate had expired when checked. | OK. |
| Wikidata | build time only (airline codes) | n/a | CC0 | OK. |

## On-map attribution

The map shows the attribution of the active style (OpenFreeMap, OpenMapTiles, OpenStreetMap contributors,
© CARTO, VersaTiles as applicable). OpenStreetMap data is under the
[ODbL](https://www.openstreetmap.org/copyright).

## Content security policy

A starting point for a site that only uses the default sources:

```
Content-Security-Policy: default-src 'self'; script-src 'self' 'unsafe-eval' 'wasm-unsafe-eval' blob:;
  style-src 'self' 'unsafe-inline'; img-src 'self' data: blob: https://pics.avs.io https://*.planespotters.net
  https://tiles.openfreemap.org https://*.basemaps.cartocdn.com https://tiles.versatiles.org;
  connect-src 'self' https://tiles.openfreemap.org https://*.basemaps.cartocdn.com https://tiles.versatiles.org
  https://api.planespotters.net https://adsb.im; worker-src blob: 'self'; font-src 'self'
```

This has not been tested against every feature, so test it before deploying and trim the hosts you disable.
