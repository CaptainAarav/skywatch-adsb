## 3D aircraft models (optional)

No aircraft model files are bundled yet: the 3D layer draws its own procedural archetypes. Real models are added with `tools/models/optimise.js`, which refuses anything whose
manifest entry (`tools/models/models-manifest.json`) does not carry a CC0 or CC-BY licence, author, source page and attribution. Every installed CC-BY model is credited here and in
Settings > About. Currently installed: none.

## Services used at run time

Nothing below is bundled. Each one receives the visitor's IP address and the request itself (for example the
map area being viewed, or an airline code). "Switch" says how a site owner or visitor can turn it off.
"Terms checked" records what was actually read; **where the terms were not found or are unclear this is said
plainly, and the service should be treated as unconfirmed.**

## On-map attribution

The map shows the attribution of the ACTIVE provider only (OpenFreeMap + OpenMapTiles + OpenStreetMap contributors; VersaTiles + OpenStreetMap contributors; or CARTO + OpenStreetMap), and it switches when the provider switches. OpenStreetMap data is under the
[ODbL](https://www.openstreetmap.org/copyright).

## Content security policy

A starting point for a site that only uses the default sources:

```
Content-Security-Policy: default-src 'self'; script-src 'self' 'unsafe-eval' 'wasm-unsafe-eval' blob:;
  style-src 'self' 'unsafe-inline'; img-src 'self' data: blob: https://pics.avs.io https://*.planespotters.net
  https://tiles.openfreemap.org https://*.basemaps.cartocdn.com https://tiles.versatiles.org https://s3.amazonaws.com;
  connect-src 'self' https://tiles.openfreemap.org https://*.basemaps.cartocdn.com https://tiles.versatiles.org
  https://s3.amazonaws.com https://api.planespotters.net https://adsb.im; worker-src blob: 'self'; font-src 'self'
```

This has not been tested against every feature, so test it before deploying and trim the hosts you disable.
